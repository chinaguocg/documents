# **管道（Pipe）** 和 **I/O 重定向（I/O Redirection）**

Shell 编程和日常系统管理中不可或缺的技能，能高效地组合简单命令来完成复杂任务。

```bash
### 核心概念：文件描述符 (File Descriptor, FD)
Shell 中默认有三个标准的数据流，每个都对应一个文件描述符编号：
1.  标准输入 (stdin) - FD 0：	默认来自键盘的输入。
2.  标准输出 (stdout) - FD 1：	默认输出到终端屏幕。
3.  标准错误 (stderr) - FD 2：	默认输出到终端屏幕，用于显示错误信息。

重定向的本质就是改变这些默认的数据流来源和目的地。
```

### 一、输出重定向 (> 和 >>)

输出重定向用于将命令的输出（本该显示在屏幕上的内容）发送到一个文件中。

#### 1. **`>` 覆盖重定向**

![](/documents/img/ops/linux/basic/pipe_redi/03.png)

* **作用**：将命令的**标准输出**重定向到文件。**如果文件已存在，则会清空原有内容后再写入**。

  ```bash
  # 将 date 命令的结果写入 date.txt 文件，而不是显示在屏幕上
  date > date.txt
  
  # 帅气的创建一个新文件（但真危险，会清空已有文件内容）
  > newfile.txt
  
  # 利用echo 创建一个单行的文件
  echo "yangge is good" > file.txt
  
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，重定向正确输出
  ls /etc/passwd /etc/xxx.txt > list.txt
  ```

#### 2. **`>>` 追加重定向**

![](/documents/img/ops/linux/basic/pipe_redi/04.png)

* **作用**：将命令的**标准输出**重定向到文件。**如果文件已存在，新内容会追加到文件末尾**。

  ```bash
  # 将磁盘使用情况追加到 log.txt 文件的末尾
  df -h >> log.txt
  
  # 再次执行，日期信息会追加在上一行后面
  date >> date.txt
  
  # 追加内容到文件 file2.txt
  echo "alice is good" >> file2.txt 
  echo "" >> file2.txt
  echo >> file2.txt
  echo "zhuzhuxia is good" >> file2.txt 
  ```

#### 3. **`2>` 和 `2>>` 错误重定向**

![](/documents/img/ops/linux/basic/pipe_redi/05.png)

* **作用**：专门重定向**标准错误**信息。

  ```bash
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，重定向错误输出【覆盖】
  ls /etc/passwd /etc/xxx.txt 2> error.txt
  
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，重定向错误输出【追加】
  ls /etc/passwd /etc/xxx.txt 2>> error.txt
  
  # 使用普通用户执行find命令，因为权限的原因，很产生大量的权限拒绝的错误消息
  $ find / -name "passwd" 2> error.txt
  ```

#### 4. **`&>` 和 `&>>` 全部重定向 **

![](/documents/img/ops/linux/basic/pipe_redi/06.png)

* **作用**：将**标准输出和标准错误**同时重定向到同一个文件。

  ```bash
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，重定向正确和错误输出
  ls /etc/passwd /etc/xxx.txt &> list.txt
  
  # 无论命令成功还是失败，所有输出都写入 output.log
  $ find / -name "yangge.txt" &> output.log
  ```

#### 5. **全部重定向方法二**

![](/documents/img/ops/linux/basic/pipe_redi/07.png)

* **作用**：将标准输出和标准错误重定向到**相同的文件**。

  ```bash
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，重定向正确和错误输出
  ls /etc/passwd /etc/xxx.txt >list.txt 2>&1
  
  # 无论命令成功还是失败，所有输出都写入 output.log
  $ find / -name "yangge.txt" >output.log 2>&1
  
  - &1: 文件描述符1（FD 1）
  ```

#### 6. **重定向到黑洞 `/dev/null`**

![](/documents/img/ops/linux/basic/pipe_redi/08.png)

- **作用**：将标准错误重定向到**空设备文件 /dev/null**。

  ```bash
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，重定向错误输出到空设备文件
  ls /etc/passwd /etc/xxx.txt 2> /dve/null
  
  # 将错误信息重定向到空设备文件（普通用户）
  $ find / -name "yangge.txt" 2> /dev/null
  
  # ls 查看文件 /etc/passwd 和 /etc/xxx.txt(文件不存在)，正确和错误全部重定向到空设备文件
  ls /etc/passwd /etc/xxx.txt &> /dev/null
  ```

### 二、输入重定向 (< 和 <<)

输入重定向用于将命令的输入源从默认的键盘改为一个文件。

#### 1. **`<` 输入重定向**

* **作用**：命令从指定的文件中读取输入，而不是从键盘。

* **语法**：`command < file`

  ```bash
  # 查看文件 /etc/hosts 的内容
  cat < /etc/hosts
  
  # 邮件内容来自 body.txt 文件（提前建立好 body.txt 文件）
  mail -s "alice你好" alice
  111
  222
  ^D
  mail -s "alice你好好好好" alice < body.txt
  
  # MySQL导入数据库文件（后面课程涉及到）
  mysql -uroot -p123 < yangge.sql
  ```

#### 2. **`<<` Here Document（此处文档）**

* **作用**：允许在命令行中直接嵌入一段多行文本作为命令的输入，直到遇到指定的 **结束标记符**。

* **语法**：`command << 结束标记符 ... text ... 结束标记符`

  ```bash
  # 创建一个多行的文件【方法一】
  cat > yangge.txt
  yangge is good
  tianyun is good
  zhuzhuxia is good
  ^D
  
  # 创建一个多行的文件【方法二】
  cat > yangge.txt << EOF
  yangge is good
  tianyun is good
  zhuzhuxia is good
  EOF
  ```

#### 3. **`<<<` Here String（此处字符串）—仅了解**

* **作用**：将单个字符串直接作为命令的输入。

* **语法**：`command <<< "string"`

  ```bash
  # cat 命令接的参数应该是文件
  [root@yangge ~]# cat "yangge is good"				
  cat: yangge is good: No such file or directory
  
  [root@yangge ~]# cat <<< "yangge is good"
  yangge is good
  
  说明：cat命令的用法
  1. 接文件名，例如: cat /etc/hosts
  2. 啥也不接，需要从键盘输入，例如: cat
  3. 使用<<<将后面字符串作为cat的输入，例如 cat <<< "11111111"
  
  # 计算字符串的单词数
  [root@yangge ~]# wc -c "yanggs is good"
  wc: yanggs is good: No such file or directory
  
  [root@yangge ~]# wc -c <<< "yanggs is good"
  15
  ```

### 三、管道 (|)

管道是 Linux 最强大和常用的功能之一。

#### 1. 基本管道使用

*   **作用**：将一个命令的**标准输出**作为另一个命令的**标准输入**。**注意：标准错误默认不会通过管道传递。**
*   **语法**：`command1 | command2 | command3 ...`
*   **理念**：组合多个单一功能的命令，完成复杂的操作。每个命令只做好一件事。

![](/documents/img/ops/linux/basic/pipe_redi/09.png)

```bash
# 查看/etc目录下文件，并通过 grep 仅过滤出目录
ls -l /etc | grep "^d"
- ^d: 以d开头的行

# 查看进程列表，过滤出 httpd 进程，并统计行数（即进程数）
yum -y install httpd
systemctl start httpd

[root@yangge ~]# ps aux | grep httpd | grep -v grep | wc -l
- ps aux: 			查看所有进程
- | grep httpd: 	过滤行中带有httpd的进程
- | grep -v grep: 	反向过滤（不要带grep）
- | wc -l: 			统计行数，即httpd进程数

# 统计 /etc/passwd 中用户使用不同 shell 的数量
[root@yangge ~]# cat /etc/passwd |awk -F":" '{print $7}' |sort |uniq -c
      2 /bin/bash
      1 /bin/sync
      1 /sbin/halt
     16 /sbin/nologin
      1 /sbin/shutdown
- cat /etc/passwd: 查看文件的全部内容
- |awk -F":" '{print $7}': 	以冒号分隔，打印每行的第7列
- |sort: 					排序（把相同的项放到一起）
- |uniq -c: 				去重，同时统计数量

# 将命令结果通过邮件发送
echo "磁盘使用率达到90%" | mail -s "磁盘使用情况" root

# 统计CPU占比最高的top 10
[root@yangge ~]# ps aux --sort=-%cpu |head -n 11 |grep -v %CPU

# 统计CPU占比最高的top 10的进程名
```

#### 2. **`tee` 管道分流**

![](/documents/img/ops/linux/basic/pipe_redi/10.png)

* `tee` 命令像一個 T 型管：**既将数据写入文件，又将其继续发送到标准输出**（以便后续管道处理）。

* **语法**：`command | tee file.txt | another_command`

  ```bash
  # 将磁盘使用情况追加到 log.txt 文件的末尾，同时也显示在屏幕上
  df -h >> log.txt
  df -h | tee log.txt
  
  # date 命令在屏幕上输出，同时保存到文件 date.txt中
  date >> date.txt
  date | tee date.txt					# 覆盖
  date | tee -a date.txt				# 追加
  
  # 将 apt update 的输出既显示在屏幕上，又保存到 update.txt 文件中
  sudo apt update | tee update.txt
  
  
  
  # tee 实战 
  [root@yangge ~]# ps aux | grep httpd | grep -v grep | wc -l
  6
  目前只能看到最终的结果！！！
  
  - 例如希望将grep httpd结果输出到httpd.log
  [root@yangge ~]# ps aux | grep httpd       |tee httpd.log         | grep -v grep | wc -l
  6
  [root@yangge ~]# cat httpd.log 
  root       1486  0.0  0.5 230444  5236 ?        Ss   09:57   0:00 /usr/sbin/httpd -DFOREGROUND
  apache     1487  0.0  0.2 230444  2976 ?        S    09:57   0:00 /usr/sbin/httpd -DFOREGROUND
  apache     1488  0.0  0.2 230444  2984 ?        S    09:57   0:00 /usr/sbin/httpd -DFOREGROUND
  apache     1489  0.0  0.3 230444  2992 ?        S    09:57   0:00 /usr/sbin/httpd -DFOREGROUND
  apache     1490  0.0  0.3 230444  2992 ?        S    09:57   0:00 /usr/sbin/httpd -DFOREGROUND
  apache     1491  0.0  0.3 230444  2992 ?        S    09:57   0:00 /usr/sbin/httpd -DFOREGROUND
  root       5030  0.0  0.0 112808   964 pts/1    S+   11:22   0:00 grep --color=auto httpd
  
  - 例如希望将grep -v grep结果输出到aaa.log
  [root@yangge ~]# ps aux | grep httpd | grep -v grep     |tee aaa.log      | wc -l
  6
  
  - 结论：希望留下哪一段的结果，就在相应的段后面增加 |tee file.txt
  ```

### 四、管道重定向总结

| 语法                  | 功能说明                                                   |
| :-------------------- | :--------------------------------------------------------- |
| `command > file`      | 将**标准输出**重定向到文件（覆盖）                         |
| `command >> file`     | 将**标准输出**重定向到文件（追加）                         |
| `command 2> file`     | 将**标准错误**重定向到文件（覆盖）                         |
| `command 2>> file`    | 将**标准错误**重定向到文件（追加）                         |
| `command &> file`     | 将**标准输出和错误**都重定向到文件（覆盖）                 |
| `command < file`      | 从文件获取**标准输入**                                     |
| `command1 | command2` | 将 `command1` 的**标准输出**作为 `command2` 的**标准输入** |
| `command << EOF`      | **Here Document**，从命令行读取多行输入直到 `EOF`          |
| `command <<< "str"`   | **Here String**，将字符串作为输入                          |
