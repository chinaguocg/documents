# CentOS Linux 路由器功能实现

  • 准备工作
  • 新建四台虚拟机，命名分别为：路由器、r1、h1、h2，系统均安装CentOS Linux 7（可以装好一台之后再克隆三台）
  • 路由器需要添加网卡
  • 路由器配置三块网卡，ens33连接外网，ens37连接r1，ens38连接h1和h2
  • 路由器配置步骤
