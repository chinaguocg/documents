# 查找命令相关练习

一、which命令

  1. 查找系统中ls命令的绝对路径。

  2. 查找gcc编译器的位置，若系统中未安装，先观察which的输出结果，再安装gcc软件包，再观察which的输出结果。

  3. 使用which命令同时查找pwd和cd两个命令的路径，分析为何cd可能无结果。

二、find命令专

  1. 在/home目录下查找所有扩展名为.txt的文件。
  2. 在/etc目录下查找名称精确为passwd的文件。
  3. 查找当前目录下所有修改时间在24小时内的文件。
  4. 查找/var/log目录下大小超过100MB的文件。（创建100M文件，dd if=/dev/zero of=/var/log/100mfile.log bs=10M count=10）

三、进阶

  1. 查找/usr/bin目录下所有属于root用户的可执行文件。

  2. 在/var/log目录下查找所有扩展名为.log且3天内未修改的文件，并将结果保存到old_logs.txt中。

  3. 查找系统中所有权限为755的目录，排除/proc和/sys目录。

  4. 使用find命令查找/opt目录下所有文件，并用ls -l查看这些文件的详细信息。

四、综合

  1. 查找/根目录下所有扩展名为.sh的文件，要求文件大小在1KB到10KB之间，且所有者为root。

  2. 查找/home目录下所有名称包含“test”的文件，将其复制到/tmp/test_files目录中（需先创建该目录）。

  3. 查找/var目录下7天前修改的.log文件，并将其删除（使用-delete参数，注意谨慎操作）。

  4. 结合which和find：先通过which找到python3的路径，再用find查找该路径所在目录下所有文件名包含“python”的文件。
